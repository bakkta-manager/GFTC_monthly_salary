# 도입부 정돈 설계

2026-10-15 · intro-refinement

## 공통 변경
기존 cinematic-scroll-intro 설계 중 도입 구조와 스크롤 규칙을 이 문서로 대체한다. house → car → statement → reality 순서다. 집과 스포츠카는 Unsplash에서 촬영 정보 및 무료 사용 표기가 확인된 온라인 사진을 다운로드하여 로컬 정적 자산으로 제공한다. 생성 이미지는 참조하지 않는다. 출처·작가·라이선스를 assets 문서에 기록한다.

첫 세 장면의 글씨는 공통 --intro-display 크기, 700 굵기, 1.35 행간, 흰색을 쓴다. PC에서 각 인용문은 한 줄, 두 번째 메시지는 ‘누구나 꿈꾸지만,’ / ‘아무나 이룰 수 없는 목표입니다.’ 두 줄이다. 강조는 두 번째 줄 ‘아무나 이룰 수 없는 목표’ 전체. 좁은 화면에서는 가독성을 위해 자연스럽게 줄바꿈하되 세 장면의 크기는 동일하다.

페이지 이동은 집→차→메시지 구간에 한정한다. 휠·트랙패드·터치 스와이프·페이지 키의 새 입력당 한 화면 이동, 관성 입력으로 두 장면을 건너뛰지 않도록 애니메이션과 동일 제스처를 잠근다. 메시지 화면부터 아래로는 일반 스크롤. 키보드 폼 조작, 링크, 브라우저 줌, 다중 터치는 그대로 동작. 작은 가로 화면에서 장면 내용이 뷰포트보다 크면 자연 스크롤을 허용한다. 모션 감소 설정에서는 즉시 이동한다. JavaScript가 없어도 모든 콘텐츠를 자연 스크롤로 읽을 수 있다.

독립 .final CTA만 제거한다. 상담 폼과 네비게이션은 유지한다.

## 통합 수입 섹션 시안
공통 콘텐츠 순서: 비현실적 수익 부정 → 세로선 / 하지만 / 세로선 → 현실적 수입 → 9년·3,165명 → 체계적인 관리 시스템하에 → 학습·훈련·행동 교정 → 결과. 각 시안 내 제목은 동일 크기, 본문은 동일 크기, 파랑은 핵심 문장 강조에만 사용한다. 과도한 장식·일러스트·판매 카드 대신 글, 여백, 구분선, 최소 체크 표시로 변주한다.

- A 정중앙: 전체 같은 중심축. 두 주장 동일 40px, 본문 17px. 세 가지 요소는 가로로 펼치되 모바일에서 세로. 마지막 결과도 중앙에서 마무리.
- B 에세이: 좁은 736px 본문. 전체 왼쪽 정렬, 두 주장 36px. 전환 세로선과 핵심 문장은 왼쪽 같은 축. 체크리스트는 글의 흐름에 삽입.
- C 여백 노트: 단일 노트의 얇은 왼쪽 여백선으로 전체 서사 연결. 두 주장 36px, 본문 17px. 하지만을 여백선의 전환점에, 관리 시스템은 경계선 아래 연결된 노트로 배치.
- D 중앙 도입·본문: 두 주장은 동일 40px 중앙 정렬, 근거 이후 읽기 좋은 560px 왼쪽 본문. 세로선은 중심에, 학습 항목은 얇은 가로선으로 구분. 기존 D의 읽기 흐름을 정돈한다.

모바일 제목은 네 시안 모두 28px, 본문 16px. 색은 제목 #f2f3f6, 본문 #bac1cc, 포인트 #7cb0ff. 크기를 내용마다 임의로 바꾸지 않는다. main에서는 기존 현실적 수입 디자인을 유지하면서 관리 내용을 같은 section 안으로 이동한다. 4개 별도 시안을 선택하기 전 임의로 확정하지 않는다.

## 시안 전달 및 검증
previews/reality-concepts.html에서 2×2 비교, 각 시안 큰 보기, PC/모바일 전환 제공. 실제 본문과 동일한 폰트·배경·폭으로 비교한다. 전체 내용을 모두 포함해 축소미리보기에서도 생략하지 않는다. 공유 사이트의 /previews/reality-concepts.html 경로로 게시.

1440×900, 1280×720, 390×844, 320×640, 844×390에서 사진 로딩, 공통 글씨 크기 일치, 첫 두 장면 페이지 이동, 일반 스크롤 복귀, CTA 삭제, 네 시안의 완전한 내용, 오버플로와 JS 오류를 확인한다. 수정 범위와 설계의 갭 분석을 함께 기록한다.

## 사용자 선택 — A 적용
사용자가 4개 시안 중 A ‘정중앙’을 선택했다. main의 reality-stage를 A와 동일한 글씨 크기·행간·굵기·색·간격으로 교체한다. 비현실적 수입과 현실적 수입 제목을 40px/700/1.45로 통일하고 본문은 17px/#bac1cc, 관리 시스템 위에 얇은 가로선, PC 체크 항목은 가로 배열한다. 모바일 제목 28px, 본문 16px, 체크 항목은 세로 배열. 스튜디오 UI·시안 footer는 main에 포함하지 않는다. 세 장면 이후 일반 스크롤 내에 표시한다.

## 연속 스크롤 수정
사용자 제보: 계속 스크롤해도 두 번째 화면에서 멈춘다. 기존 wheel 잠금 분기에서 매 이벤트마다 만료 시각을 연장하여 연속 입력이 무한히 차단되는 문제를 확인했다.

휠 페이지 전환의 보호 구간을 전환 시작 기준 760ms로 고정한다. 보호 구간 내 추가 입력은 만료 시각을 연장하지 않는다. 620ms 이동 애니메이션 뒤 짧은 140ms 보호 구간이 지나면 다음 입력을 받는다. 연속 스크롤은 다음 장면으로 계속 진행하며, 메시지 화면 이후 일반 스크롤로 해제된다. 기존 키보드·터치·모션 감소 처리와 디자인은 유지한다.

검증에 3초 이상 멈추지 않는 연속 휠 입력을 추가한다. 짧은 입력은 한 장면으로, 연속 입력은 두 번째 화면을 지나 본문으로, 역방향 연속 입력은 첫 화면으로 도달해야 한다.


## 공유용 도입 사진 제거
사용자가 우선 공유할 수 있도록 고급 집·스포츠카 사진 제거까지만 진행하도록 요청했다. 두 img DOM을 삭제하고 wealth-stage 배경을 기존 #0a0b0f로 통일한다. 사진용 오버레이와 글자 그림자는 제거한다. 화면 분리·글씨 크기·스크롤은 유지하고 기존 공개 링크에 즉시 반영한다. 하이라이트·하지만 확대·근거 문장 시안 작업은 이번에 진행하지 않는다.

## 사용자 요청 — 어두운 생성 배경 추가
사용자가 직접 제공한 참고 분위기를 바탕으로 내장 image_gen으로 새 이미지를 생성하도록 요청했다. 이전 사진 제거 상태에서 첫 두 장면에만 새로운 배경을 추가한다.
- 첫 장면: 검은 석재 외벽의 현대식 3층 주택, 야간과 은은한 실내 조명. assets/intro-house-generated-v1.webp.
- 두 번째 장면: 계단 위 검은 고급 세단의 측면, 어두운 하늘과 절제된 테두리 조명. assets/intro-car-generated-v1.webp.
- 데스크톱은 전체 화면을 채우고 어두운 오버레이와 작은 글자 그림자로 기존 흰 문구의 가독성을 확보한다. 모바일은 자동차 전체가 보이도록 이미지 비율을 유지하고 상하를 어두운 배경으로 부드럽게 연결한다.
- 이미지에는 글자·UI를 생성하지 않는다. 제목은 기존 HTML·폰트·크기·배치를 유지한다. 스크롤 로직 및 세 번째 장면, 수정된 현실 섹션의 행간은 보존한다.
- 이미지 원본은 보관하고 웹용 WebP로 저장한다. 생성 프롬프트와 원본 경로를 assets/generated-intro-images.md에 기록한다. PC·모바일에서 이미지 로딩, 가독성, 여백, 넘침과 페이지 전환을 확인한다.

## 사용자 후속 요청 — 스포츠카·오버레이·신문 배경
- 자동차는 새로 생성한 낮은 검은 2도어 스포츠카(v2)로 교체하고, 계단과 바닥의 가로 줄무늬를 모두 없앤 매끈한 바닥을 사용한다.
- 집과 차의 검은 오버레이 불투명도를 PC·모바일 모두 높인다. 글씨와 스크롤 동작은 유지한다.
- 세 번째 ‘누구나 꿈꾸지만’ 장면에는 코인·투자 성공을 다루는 가상의 신문 더미 이미지를 새로 생성하여 배경에 배치한다. 사용자가 지정한 Higgsfield의 GPT Image 2.5, 16:9, 2K, high 설정을 사용한다.
- 신문은 장면 전체를 채우고 어두운 오버레이를 적용한다. 기존 제목의 크기, 두 줄 구성, 강조와 화면 중앙 위치는 유지한다.
- 현실적 수입 섹션은 대표님 사진 없이 기존의 따뜻한 단색 배경을 유지한다.
- 자동차 추가 조정: 자동차 섹션 오버레이만 각 지점의 불투명도를 10%p 올린다. PC는 68/72/58/92%, 모바일은 45/65/50/80%로 조정한다.
- 신문 배경 추가 조정: statement-stage 검은 오버레이를 60/72/65%에서 74/84/78%로 높인다. PC·모바일 공통이며 제목·강조·이미지 배치는 유지한다.

# 하단 안내 사항 설계

2026-10-15 · footer-notice

- 위치: 상담 신청 section 바로 뒤, footer 앞. 기존 .wrap으로 본문과 좌우 정렬.
- 구조: .site-notice 여백 컨테이너 내부에 aside.notice-panel, aria-labelledby=notice-title. h2 제목, 장식용 작은 경고 SVG, 구분선 및 ul 세 항목.
- 배경 #10151d, 테두리 #ffffff18, 모서리 12px. 패널 padding 28px, 외부 위아래 여백 48px/64px. 제목 18px/1.5·500·#f2f3f6, 아이콘 20px·#91b1e0. 제목 아래 20px/1px 구분선, 목록 시작 20px.
- 본문 16px/1.9, 색상 #a5afbd, 항목 간격 16px, 작은 파란 bullet. 긴 문장은 자연스럽게 줄바꿈. 640px 이하 패널 padding 22px 20px 및 외부 여백 32px/44px.
- 문구는 이미지 원문 그대로: 투자 자문·일임 부인 및 수익 보장·매매 지시 부인, 학습·데이터 분석 목적 및 개인 투자 판단 책임, 후기·원화 기준금액 관련 세 항목.
- 안내는 항상 표시하며 클릭/애니메이션/접기 기능은 추가하지 않는다. 기존 혜택 효과와 다른 섹션은 유지.
- 후속 요청: .site-notice 바깥 배경을 상담 폼 섹션 .apply와 동일한 var(--bg2)로 통일한다. 내부 패널은 기존 색을 유지한다.
- 검증: 원문 세 문장 대조, 1440/390/320px 배치·넘침·가독성, 상담 신청 뒤/푸터 앞 순서 확인. 기본 공유 주소에는 섹션 해시를 붙이지 않는다.

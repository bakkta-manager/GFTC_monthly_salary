# 수입 설명 디자인 발전 시안 설계

2026-10-15

## 공통
A 웜 페이퍼 색상, Pretendard, 제목40px/모바일28px, 본문/근거/체크/결과 모두17px/16px. 체크3개는 세로, 목록 중앙·항목 왼쪽정렬. 문구와 숫자 강조, 하지만 연결 유지. 글이 중심이고 이미지/새로운수치/새문구 추가 없음.

## 네 시안
- A 단정한 중심: 섹션 너비680px, 현재 중심축과 여백을 조금 압축. 하지만 양옆 짧은 가로선, 상하 문장을 한 호흡으로. 하단은 얇은 중앙 구분선.
- B 한 장의 편지: 배경은 옅은 회베이지, 중앙 종이 면840px에1px 외곽선과 넉넉한 여백. 세로 하지만 연결, 공통본문과체크. 모바일은 바깥여백12px와 안쪽20px.
- C 조용한 주석: 처음 문구는 회색 밑줄, 결론은 파란 밑줄. 숫자 근거 문장에 옅은 흰 노트배경과 왼쪽 파란선. 하단 관리/체크는 얇은 위아래선으로 정리. 제목 크기와 중심정렬 유지.
- D 푸른 단락: 결론+근거만 옅은 파란 문단 면으로 묶고, 앞문장과 하단실천은 웜페이퍼. 같은 크기 제목과 숫자하이라이트. 카드내추가제목/아이콘 없음.

## 2026-10-15 추가 요청 — 강조 위치와 종이 질감
- 현재 전체 화면 레이아웃, 문구, 글자 크기와 중앙 정렬을 유지한다.
- 결론의 하이라이트를 ‘현실적으로 가능’에서 ‘월급만큼의 수입’으로 이동하고 조사 ‘은’은 제외한다.
- 수입 설명 섹션에만 정적인 미세 입자와 옅은 명암으로 종이 질감을 추가한다.
- 기존 밝은 바탕과 가독성을 유지하며 장식 레이어는 클릭을 가로채지 않는다.
- 사이트 문구의 맞춤법 검토는 보고만 하고 교정은 적용하지 않는다.

## 2026-10-15 후속 승인 — 검토 사항 전체 반영
- 사용자의 ‘전부 반영해’ 요청에 따라 보고한 띄어쓰기 5곳과 문장·표기 수정 사항을 적용한다.
- ‘않을 겁니다’, ‘한두 번’, ‘편할 겁니다’, ‘수강생분들에게’, ‘월수입’ 표기를 사용한다.
- 매매 내역 문장의 중복을 제거하고 조사를 보완한다. ZOOM, 매매 일지, 라이브 트레이딩, 기준 금액, 수집·이용 표기를 통일한다.
- 본문 두 문장에 마침표를 추가하고 지원 동기 안내의 끊어진 문장을 연결한다. 개인정보 동의 오류 문구도 같은 표기로 맞춘다.
- 레이아웃, 강조, 애니메이션, 폼 저장 및 검증 로직은 유지하고 수정 문자열과 차이를 확인한 뒤 게시한다.

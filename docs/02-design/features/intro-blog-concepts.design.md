# 블로그형 시안 설계

2026-10-15 · 사용자 교정 내용을 최우선 기준으로 적용.

## 불변 요소
- index.html의 첫 두 letter 블록 문장 전체 및 순서 유지.
- 중앙 정렬된 max-width 736px의 한 열, 실제 본문 폭 688px, 어두운 배경 #0A0B0F.
- IBM Plex Sans KR, 본문 17px/1.8, 기본 제목 36px. 원래 네비게이션 형태.
- 체크리스트는 본문에 붙은 세로 목록. 숫자는 문장 안에 배치.
- 기존 세 번째 섹션의 제목과 첫 문단을 아래 연결부로 표시.

## 시안 네 가지
| 시안 | 이미지 위치 | 강조 | 모션 |
|---|---|---|---|
| A 원문 정돈 | 첫 섹션 마지막, 얕은 야간 데스크 사진 | 원래 파란 밑줄, 제목 36px, 마지막 결론 19px | 제목·이미지 8px 등장 |

| C 기록 삽입 | 교육 경험 문장 뒤, 학습 노트 사진 | 원래 제목 36px, 문장 속 9년·3,165명만 21px | 사진·체크 항목 순차 등장 |

## 공통 구현
하나의 원문 템플릿과 스타일 변형을 사용한다. 문장은 직접 재작성하지 않고 index.html에서 추출한다. 사진 1장, 본문 폭 이내 높이 180~235px. 생성 이미지 editorial/evidence 재사용. 별도 영문 헤드라인이나 광고 구호를 추가하지 않는다.

비교 화면 → 개별 시안 → PC/모바일 전환·모션 다시 보기. 대표 제목의 모바일 크기 28~30px. 이미지 모바일 높이 150~185px. 모션은 한 번만 동작하며 prefers-reduced-motion을 존중한다. 원래 글 비교용 O 탭도 추가한다.

## 검증
4개 시안 × 1440px/390px/320px에서 이미지 및 가로 넘침 확인. DOM 텍스트를 원본과 비교해 첫 두 섹션 내용·순서 일치 확인. PC와 모바일 화면을 육안 확인. 비교·원문·리플레이 전환 확인.

## 추가 구간: 세 가지 문제
원본 index.html의 해당 eyebrow 문구만 삭제하고 h2, 설명, 세 가지 항목의 모든 본문과 순서를 유지한다. 같은 A/B/C/D 선택지 안에서 별도로 비교할 수 있도록 section=intro|problems 필터를 제공한다. 총 8안이며 각 구간별 원문 비교 포함.

| 시안 | 세 가지 문제 변주 |
|---|---|
| A 원문 정돈 | 배경 박스 대신 문단 사이 얇은 구분선, 핵심 문장 밑줄 |
| B 인용 강조 | 작은 장 번호와 편집형 제목, 파란 선으로 핵심 인용 |
| C 기록 삽입 | 노트처럼 왼쪽 여백 선, 핵심 문장 은은한 형광펜 |
| D 문장 집중 | 기존 세로 글 흐름에서 제목과 핵심 문장만 크게, 절제된 강조 박스 |

두 구간은 하나의 비교 화면에서 전환한다. 원본 문구 삭제는 사용자 명시 요청이며 index.html의 유일한 변경이다. 문제 구간에는 내용에 불필요한 이미지를 추가하지 않는다.

## 최종 선택 및 원본 적용
사용자가 세 가지 문제 구간의 C 기록형을 선택했다. index.html의 해당 구간에 세로 여백선, 파란 점, 배경 박스 없는 문단, 핵심 문장의 형광펜 표시를 그대로 적용한다. 데스크톱·모바일의 여백과 제목 크기는 C 미리보기와 동일하게 맞춘다. 등장 효과는 한 번만 적용하고 모션 감소 설정에서 비활성화한다.

도입부는 선택된 시안이 없으므로 원본 HTML과 관련 스타일을 유지한다. 문제 구간 본문은 한 글자도 바꾸지 않는다. 원본의 다른 구간과 폼 동작에 영향이 없도록 CSS와 모션을 problems 구간에 한정한다.

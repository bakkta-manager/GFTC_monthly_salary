# 월 수강료 및 기간 안내 설계

Date: 2026-10-24
Plan: ../../01-plan/features/monthly-price-duration.plan.md

- #curriculum 전체(제목/설명/흰색 블러 문서/공개 안내) 삭제. 전용 CSS 블록과 공통 선택자/모션에서 curriculum 참조 제거.
- meta description의 ‘9개월 소수 정예 트레이딩 훈련’ → ‘월 29만 원의 소수 정예 트레이딩 훈련’.
- 첫째 항목의 ‘협회가 권장하는 교육 기간은 9개월입니다’ 강조 행 삭제. 세 번째 항목에서 ‘9개월 동안’만 제거.
- 상담 폼의 ‘9개월 과정을 끝까지 소화할 의향이 있으신가요?’ → ‘학습과 훈련에 꾸준히 참여할 의향이 있으신가요?’. name=duration, 기존 선택값과 필수 검증은 유지한다.
- 상담 신청 소개 아래, 폼 위에 ‘수강료 / 월 29만 원’의 간결한 한 줄 안내 추가. 새 독립 섹션은 만들지 않는다. 기존 콘텐츠 폭/폰트와 어울리는 22–28px 가격, 얇은 구분선 사용.
- 9개월을 대체할 다른 교육 기간, 최소 이용 기간, 자동 결제, 부가세/환불 조건을 추가하지 않는다.
- 최근 통일한 읽기 레이아웃, 원래 도입부, 다른 혜택/문구 및 폼 API는 보존한다.

검증: 9개월/커리큘럼 섹션 잔존 없음, 가격 표시, HTML 내부 앵커와 JS 구문 유효, 폼 필드/허용값 동일, 320/390/1440px 가로 넘침과 스크립트 오류 없음, 상담 소개/연결 구간 스크린샷 확인. 같은 공개 주소에 배포한다.

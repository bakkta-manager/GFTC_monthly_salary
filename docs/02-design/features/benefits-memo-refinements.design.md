# F 메모형 발전 설계

2026-10-15 · benefits-memo-refinements

## 공통 요소
원본 benefits 문구, 6개 항목 순서, 전체 폭 736px, 2열 배치와 작은 선 아이콘 유지. 모바일 640px 이하 한 열. IBM Plex Sans KR, #0A0B0F 배경, 낮은 채도의 파란색. 본문 중심이며 이미지·광고 헤드라인·CTA를 추가하지 않는다.

## 4개 발전안
| 시안 | 배치 | 발전 포인트 |
|---|---|---|
| F1 정돈한 메모 | 아이콘과 제목을 한 줄의 헤더로 | 본문 16px, 선명한 제목과 정돈된 패딩, 6px 모서리와 얇은 테두리 |
| F2 요점이 보이는 메모 | 기존 위쪽 아이콘 유지 | 설명 첫 문장을 밝게 분리, 카드 위 짧은 파란 선, 본문 15px |
| F3 여백이 있는 메모 | 아이콘과 작은 항목 번호, 제목 아래 구분선 | 넉넉한 여백, 16px 본문, 각 메모의 문서 같은 구성 |
| F4 한 장의 노트 | 6개 메모를 하나의 2열 패널로 연결 | 카드 사이 틈 대신 내부 구분선, 작은 아이콘 영역, 16px 본문 |

## 모션 및 접근성
한 번의 8px 등장 효과. 항목은 클릭 카드가 아니며 링크처럼 보이는 화살표를 붙이지 않는다. 아이콘·번호는 장식으로 취급하고 내용을 가리지 않는다. reduced-motion에서 모션 비활성화. 문장은 DOM에서 선택 가능.

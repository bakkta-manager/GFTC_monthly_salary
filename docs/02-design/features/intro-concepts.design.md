# 도입부 시안 설계

Date: 2026-10-15 · Feature: intro-concepts

## 화면 및 흐름
비교 화면 → A/B/C/D 개별 시안 → PC 또는 모바일 폭 전환 → 모션 다시 보기.
각 개별 시안은 브랜드 헤더, 요청한 도입부 두 섹션의 재구성, 다음 본문 연결 버튼으로 구성한다. 버튼은 기존 페이지 본문으로 연결한다.

## 시안 구성
| 시안 | 배치 | 이미지 | 타이포그래피 | 모션 |
|---|---|---|---|---|
| A 시네마틱 레터 | 넓은 이미지 위 부정 명제 → 아래 편지와 수치 → 3개 번호 행 | 야간 데스크 | 64px 제목, 48px 결론, 블루 밑줄 | 제목 순차 등장, 밑줄 그리기, 스크롤 등장 |
| B 관점의 전환 | 도시 이미지 좌측 / 큰 결론 우측, 하단 3개 훈련 | 새벽 도시 전경 | 억제한 부정 명제, 72px 긍정 명제 | 좌우 등장, 하지만 연결점, 훈련 순차 강조 |
| C 경험의 무게 | 밝은 바탕, 상단 9년·3,165명, 본문과 노트 사진 분할 | 학습 노트 | 104px 숫자, 세리프 포인트, 52px 결론 | 수치 카운트, 이미지 부드러운 등장 |
| D 훈련의 구조 | 헤드라인과 유리 계단 이미지, 하단 연결된 3단계 | 유리 계단 오브젝트 | 68px 결론, 모노 숫자, 작은 라벨 | 이미지 최초 진입, 단계 진행선과 순차 활성화 |

## 반응형
콘텐츠 최대 폭 1180px, 760px 아래 모든 분할을 단일 열로 전환. 390px에서 제목 38~44px, 본문 15~17px. 3개 훈련 요소는 모바일에서 세로 흐름. 320px까지 가로 넘침 방지.

## 이미지 및 문구
이미지는 AI로 제작한 컨셉 연출 이미지. 사진을 실제 강의·수강생 기록으로 설명하지 않는다. 원문의 9년·3,165명과 수입 관련 핵심 문장은 그대로 사용하며 추가 성과 수치는 만들지 않는다. 그림은 교육 과정의 비유로만 활용한다.

## 구현
자체 완결 HTML/CSS/JS, CSS 커스텀 속성, semantic headings, template별 구성, IntersectionObserver 기반 등장/카운트 모션. 비교 화면에 iframe 미리보기. query concept=a|b|c|d, embed=1 지원. 실제 DOM 텍스트로 제공해 모바일에서도 선명하게 읽힌다.

## 접근성과 검증
키보드 작동 버튼, 활성 시안 aria-current, 이미지 alt, 충분한 대비, reduced-motion에서 모든 모션 제거 및 최종 숫자 즉시 표시. Playwright로 1440px/390px 스크린샷, 이미지 로드, 오류, 가로 넘침, 시안 전환 및 다시 보기 확인.

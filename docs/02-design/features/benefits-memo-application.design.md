# 제공 혜택 F4 적용 설계

2026-10-15 · benefits-memo-application

기준: previews/benefits-memo-refinements.html?concept=f4&embed=1&still=1 및 사용자가 선택한 스크린샷.

- index.html의 .benefits에 id=benefits를 추가하고 해당 섹션 범위에만 스타일 적용.
- 최대 본문 폭 736px 및 기존 .wrap 유지. 섹션 패딩 76px/64px, 제목 36px, 설명 17px.
- .blist를 간격 없는 2열 패널로 구성. 배경 #10151d, 1px 외곽선, 모서리 8px.
- 각 항목 패딩 27px 25px 30px. 첫 행을 제외한 위쪽 및 오른쪽 열 왼쪽에 내부 구분선.
- 각 제목 앞에 시안과 동일한 aria-hidden SVG를 정적 마크업으로 삽입. 30px 아이콘 영역, 제목 18px/1.6, 헤더 최소 높이 65px 및 아래 여백 12px. 본문 16px/1.9, #a5afbd.
- 640px 이하 한 열. 패딩 25px 23px 27px, 제목 19px, 헤더 최소 높이 해제, 아래 여백 18px. 모든 내부 세로선을 제거하고 두 번째 항목부터 가로선 적용. 360px 이하 좌우 패딩 19px, 제목 18px.
- 제목 및 항목에 8px 한 번의 등장 효과. 모션 감소 또는 IntersectionObserver 미지원 시 항상 보이게 유지. JS 없이 본문과 아이콘 표시.
- 검증: 1440/390/320px에서 시안 대비 계산 스타일·상대 배치·문구·아이콘 일치, 넘침과 콘솔 오류, 등장 효과 및 모션 감소 확인. 혜택 영역 외 변경 없음 확인.

## 2026-10-15 개정: 독립 카드 + 이동하는 강조 배경

이 개정은 위의 단일 패널·내부 구분선 규칙을 대체한다.

- 참고: https://ui.aceternity.com/components/card-hover-effect 및 사용자 제공 데모. 마우스로 선택한 카드 뒤로 한 장의 강조 배경이 부드럽게 이동한다.
- .blist는 투명한 2열 grid, 가로·세로 간격 20px. 각 li는 독립 배경 #10151d, 1px 테두리, 12px 모서리. 640px 이하 1열, 간격 16px. 카드 패딩·문구·아이콘·본문 크기 유지.
- ul의 장식용 ::before 레이어를 각 카드보다 사방 6px 넓게 표시한다. 톤은 #24344c, 모서리 18px. 위치·크기는 280ms, 나타남/사라짐은 150ms. 콘텐츠는 카드 위에 고정된다.
- pointerover로 카드 위치를 추적하고 pointerleave 시 숨긴다. 카드 사이 간격에서는 강조가 끊기지 않는다. 최초 진입은 현재 카드에서 바로 나타난다. ResizeObserver로 크기 변경 시 위치를 다시 맞춘다.
- 기존 정적 HTML 구조에서 동일한 동작을 CSS/JS로 구현한다. 카드에 의미 없는 링크·탭 정지점·버튼 역할을 추가하지 않는다.
- 터치 기기는 정적 카드로 읽으며 스크롤 입력을 차단하지 않는다. prefers-reduced-motion에서는 이동/페이드 없이 즉시 강조한다. JS를 끈 경우에도 카드 내용과 간격이 유지된다.
- 검증: 1440/390/320px 레이아웃, 카드 간 이동 중간 프레임 및 최종 위치, 퇴장·재진입·크기변경, 모션 감소와 터치, 문구 보존·콘솔 오류·가로 넘침. 공개 배포 후 첫 화면부터 시작하는 기본 링크 제공.

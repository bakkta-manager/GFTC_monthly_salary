# 도입부 연결 시안 설계

2026-10-15 · intro-connection-concepts

## 화면과 흐름
previews/intro-connection-concepts.html에 4안 비교 → A/B/C/D 상세 → PC/모바일 및 다시 보기 흐름을 제공한다. 현재 배치를 별도 비교 탭으로 제공한다. 갤러리 iframe은 실제 콘텐츠 높이에 맞추어 자르지 않는다.

## 공통 기준
원본의 첫 두 letter 블록을 추출해 동일한 글과 체크리스트를 사용한다. 배경 #0a0b0f, IBM Plex Sans KR, 본문 17px/1.8, 제목 36px, 폭 736px. 640px 이하에는 좌우 20px, 제목 28px, 본문 16px. 새로운 이미지·홍보 문구·카드를 본문에 추가하지 않는다. 필요한 등장 효과는 6px 한 번의 페이드이며 모션 감소를 지원한다.

## 시안
| 시안 | 연결 방식 | 자연스러움의 기준 |
|---|---|---|
| A 본문 흐름형 · 우선 추천 | 기존 세로선 / 하지만 / 세로선을 본문 왼쪽으로 이동, 선 길이와 여백 축소 | 본문 시작선에서 다음 문단으로 읽는 흐름 유지 |
| B 여백 기록형 | 본문 옆 얇은 세로 여백선을 연결하고 ‘하지만’을 그 옆 전환 지점에 배치 | 앞서 선택한 기록형의 문서 톤과 일관성 |
| C 문장 전환형 | 짧은 세로선이 ‘하지만’에서 두 번째 제목 옆 선으로 이어짐 | ‘하지만’을 다음 문장 도입으로 읽게 함 |
| D 도입 정렬형 | 앞 도입·세로 연결·다음 제목의 중앙축을 맞추고 상세 설명은 왼쪽 | 중앙 연결을 유지하면서 앞뒤 정렬의 충돌 해소 |

## 검증
4안 × 1440/390/320px에서 원문, 하지만 1개, 제목 및 본문 넘침, 연결선과 글자 겹침, 오류 확인. 실제 렌더와 PC/모바일 전환 및 모션 감소 확인. 최종 추천은 렌더를 보고 결정한다. index.html 해시 유지.

# 사이트 모션 보완 설계

2026-10-15 · site-motion-polish

기존 intro-refinement, reality-letter-application, benefits-memo-application의 최종 배치와 문구를 기준으로 모션만 보완한다.

1. CSS는 기존 스타일 뒤에 추가한다. 새 모션은 `prefers-reduced-motion: no-preference` 안에서만 활성화한다. IntersectionObserver 지원 시에만 html.motion-ready를 추가한다.
2. 사용자 추가 요청: 집·스포츠카·신문 원본 이미지를 Higgsfield Kling 3.0 Turbo로 각각 5초, 1080p 영상으로 생성한다. 약2%의 느린 카메라 이동과 미세한 빛·자연 움직임만 허용한다. 기존 어두운 오버레이와 텍스트 위치를 유지한다. 모바일 자동차 구도와 기존 스크롤 로직을 유지한다.
3. 장면 화살표: 1.6초에 4px 내려갔다 돌아오는 동작을 세 번만 재생한다. 강조 mark와 문제 key-ink는 0→100% 배경 너비를 약1초에 그린다. 현실 구간 세로선은 scaleY로 0.65초간 한 번 나타난다.
4. 본문·커리큘럼·혜택 부제·폼 제목: motion-item 대상으로 지정해 18px 아래에서 0.7초간 등장. 인접 항목 간 지연은 최대120ms. 기존 도입·문제·혜택 카드 observer 대상과 중복하지 않는다. 각 항목 진입 후 unobserve하여 반복되지 않는다.
5. 혜택 카드: 기존 이동 배경을 유지하고 hover 가능한 마우스에서만 4px 들어올림, 작은 아이콘 기울기 및 부드러운 그림자를 추가한다. 좌표 계산용 offsetLeft/Top은 변하지 않는다.
6. 버튼: hover/focus에서 0.65초 빛줄기와 2px 들어올림, disabled 제외. 폼 단계 변경에 0.3초 페이드, 선택 칩은 색상·테두리 전환을 부드럽게 한다. 필드·폼 자체는 숨기지 않는다.
7. 저감 모션 전환 시 새 observer를 해제하고 모든 내용을 즉시 표시한다. JavaScript 비활성·IntersectionObserver 부재에서도 내용은 기본 표시. 인쇄 시 기존·신규 등장 효과를 모두 해제한다.
8. 검증: desktop/mobile 실제 등장 중간/완료 스타일, 사진·화살표·강조선, 카드 호버, 빠른 스크롤과 첫 두 장면 이동, 폼 유효성/단계 이동, 동작 줄이기(초기/실시간), JS/IO 미지원, 내용 동일 및 가로 넘침을 확인한다.

영상 구현: 원본 이미지 위에 muted/playsinline/loop video를 장식 레이어로 두고 canplay 뒤에만 표시한다. 화면 진입 시 지연 로딩·재생, 화면 밖/비활성 탭에서는 정지한다. 동작 줄이기 및 데이터 절약 설정에서는 이미지를 표시한다. autoplay 거부·오류 때도 이미지가 남는다. 각 장면에 작은 배경 영상 일시정지/재생 버튼을 제공한다. 출력은 오디오 없는 H.264/faststart로 최적화하며 반복 연결을 검수한다. 생성 기록과 프롬프트를 보관한다.

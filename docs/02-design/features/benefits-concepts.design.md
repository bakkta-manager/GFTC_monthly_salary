# 제공 혜택 디자인 시안

2026-10-15 · benefits-concepts

## 공통
원본 benefits 섹션을 하나의 템플릿으로 사용한다. 제목과 설명을 바꾸지 않고 CSS와 장식 span만으로 변형한다. 원래 섹션 제목·eyebrow·설명 유지. PC 본문 폭 736px(좌우 padding 24px), 모바일 padding 20px, 본문 17px/1.85 및 모바일 15~16px. IBM Plex Sans KR, #0A0B0F 배경과 파란 강조색. 내용이 메인이므로 대형 이미지, 성과 숫자, CTA는 추가하지 않는다.

## 6개 방향
| 시안 | 구조 | 포인트 |
|---|---|---|
| A 문단형 | 한 열, 제목 다음 설명 | 얇은 가로 구분선과 충분한 문단 간격 |
| B 기록형 | 한 열, 연결된 여백선 | 선택한 문제 구간 C와 통일된 파란 점·세로선 |
| C 사전형 | 행마다 왼쪽 제목, 오른쪽 설명 | 사전의 표제어처럼 읽는 2단 텍스트 구조; 모바일 세로 |
| D 목차형 | 기존 2열 유지 | 작은 01~06 번호, 항목 위 가로선, 명확한 제목 |
| E 문장형 | 한 열, 작은 제목과 큰 핵심 문장 | 각 설명의 첫 문장을 은은한 형광펜으로 강조 |
| F 메모형 | 2열의 절제된 메모 블록 | 작은 선 아이콘·얕은 배경·메모 여백; 모바일 한 열 |

## 모션
제목 및 항목의 8px 일회성 등장만 사용한다. 작은 강조선·아이콘은 본문보다 먼저 눈에 띄지 않게 한다. prefers-reduced-motion에서 본문 즉시 표시. 정보는 모션과 무관하게 DOM에 존재한다.

## 비교 화면
전체 6안 갤러리 → A~F 개별 보기 → 원문 비교, PC/모바일 폭 전환, 모션 다시 보기. 갤러리 썸네일은 각 시안의 실제 높이에 맞춰 전체 6개 혜택이 보이게 한다. 이전 도입·문제 시안 링크도 제공한다.

## 검증
6안 × 1440px/390px/320px에서 제목·설명 순서와 원문 일치, 가로 넘침, 자바스크립트 오류를 확인한다. 실제 렌더를 육안 확인하고 모바일 전환·갤러리 링크·모션 감소를 점검한다.

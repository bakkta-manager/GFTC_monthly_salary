# 도입 간격과 폰트 6종 비교 설계

2026-10-15 · intro-font-concepts

## 메인 정리
- statement h1은 기존 공통 글자 크기·색을 유지하고 line-height 1.18, 두 블록 사이 gap .12em으로 정리한다. opening의 기존 .24em margin은 제거한다. 하이라이트는 font metric을 따라 길어지는 inline 배경 대신 em 고정 높이 .28em, 아래 .05em의 background image를 쓴다. 강조 범위는 ‘아무나 이룰 수 없는 목표’ 유지. 모바일 자연 줄바꿈 유지.
- ‘협회의 오랜 고민이 오히려 가장 큰 보람이 될 것입니다.’와 ‘이런 고민 끝에 내놓은 것이 월급반입니다.’는 하나의 p에서 br로 구분하며 기존 본문 17px/400/흰색을 동일 적용한다. 대표 서명·strong·sig 위계를 제거한다.
- 문제 리스트 외곽 border-left 대신 absolute rail을 사용한다. PC top 25.5px / 모바일 22.5px부터 시작해 첫 점 중심보다 위로 선이 나오지 않는다. 나머지 점·연결선 유지.
- 문제 설명은 문장 끝과 긴 의미 단위에서 br로 구분한다. 혜택 카드 p는 마침표 뒤마다 br, W.E.T 제목 및 원문은 그대로 유지한다.

## 6개 폰트
A Pretendard / B SUIT / C Noto Sans KR / D Wanted Sans / E 나눔스퀘어 네오 / F Noto Serif KR. 실제 폰트 파일을 제공자 공식 배포에서 가져와 로컬로 제공한다. 출처 및 라이선스 보관.

previews/font-concepts.html에서 2열×3행 비교. 각 카드에는 동일한 문구·배경·크기·행간·하이라이트를 적용해 글꼴 차이만 비교한다. A~F 탭, 각 시안 크게 보기, PC/모바일 전환, 실제 사이트 링크 제공. 큰 보기에서는 도입 문구 및 현실적 수입 제목·근거 문장까지 해당 폰트로 읽어 볼 수 있다. 제목700, 본문400. 글자 크기 및 간격 모두 공통 토큰. 글꼴은 사용자 선택 전 메인에 적용하지 않는다.

## 검증
실제 폰트 파일 로딩(이름·요청 성공) 및 6종 모두의 PC/390px/320px 오버플로 확인. 동일 제목 크기·행간, 메인 간격 감소, 서명 제거·동일 위계, rail 시작점, 설명 문장별 줄바꿈, 기존 카드 이동 효과 보존. 페이지 스크롤 JS 변경 없음. 공용 사이트에는 수정본과 폰트 비교 페이지를 함께 게시한다.

## 사용자 선택: A Pretendard 적용

사용자가 A 시안을 확정했다. 메인의 공통 --sans를 Pretendard로 변경해 도입·제목·본문·카드·폼·하단 안내에 동일 적용한다. 시안에 사용한 assets/fonts/pretendard.woff2를 로컬 @font-face(100–900)로 불러오고 preload한다. IBM Google Fonts 외부 로딩은 메인에서 제거한다. 선택한 시안의 도입 간격 1.18/.12em 및 하이라이트 .28em은 현재 적용값을 유지한다. 기존 폰트 크기·굵기·문구·줄바꿈·스크롤·호버 동작은 유지한다. PC/모바일 실제 Pretendard 렌더링 및 넘침, 첫 세 장면 동일 폰트 크기를 확인 후 기존 공개 주소로 배포한다.

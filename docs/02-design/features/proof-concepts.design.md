# 근거 문장 시안 설계

2026-10-15 · proof-concepts

## 실제 페이지 공통 수정
index.html의 .reality-limit에서 ‘비현실적인 수익’만 mark로 감싼다. 기존 현실적 수입 제목과 같은 파란 아래쪽 하이라이트를 사용한다. 양 제목의 글꼴·크기·색·굵기는 유지한다.

하지만 연결은 17→24px(모바일 16→21px), 위·아래 세로선 22→34px(모바일 18→28px)로 확대한다. 선 너비 1px, gap 12px(모바일 10px), 문단 간격은 28px(모바일 24px). 기존 중간 글자색과 500 굵기를 유지하여 두 주장 제목보다 작게 연결한다.

## 근거 문장 4개 시안
현재 선택된 A 정중앙 레이아웃과 본문을 모든 시안에서 공유한다. 공통 수정인 하이라이트·확대된 하지만도 시안에 반영한다. 변화는 근거 문장 부분에 한정한다. 주장은 40px/모바일28px, 본문17px/모바일16px, 핵심 숫자 최대36px로 제한한다. 색은 기존 흰색·회색·파랑만 사용한다.

- A 문장 강조: 기존 문장 흐름을 유지하며 ‘9년간’과 ‘3,165명’을 같은 크기의 굵은 글씨와 파란 밑줄로 강조. 20px/모바일17px.
- B 두 줄 기록: ‘9년간 3,165명을 가르쳐본 결과,’ / ‘내린 결론입니다.’ 두 줄. 첫 줄22px/모바일18px, 다음 줄17px/모바일16px. 양옆 짧은 얇은 선으로 기록처럼 마무리.
- C 숫자 중심: 9년간 · 3,165명을 하나의 중앙 행에 두고 숫자만36px/모바일30px. 접미사는 본문 크기. 아래에 ‘가르쳐본 결과 내린 결론입니다.’ 본문 크기로 연결. 과장된 카운터·카드·애니메이션 없이 숫자를 읽기 쉽게 제시.
- D 여백 인용: 최대560px 폭의 낮은 대비 노트 배경과 얇은 파란 왼쪽 선, 중앙 두 줄 문장. 본문18px/모바일17px. 숫자는 같은 크기로 굵게.

## 전달
previews/proof-concepts.html의 2×2 갤러리에서 바뀌는 근거 문장과 직전 제목을 비교한다. 시안 클릭 시 전체 A 섹션을 큰 화면으로 보여주고 PC·모바일 전환을 제공한다. 갤러리 썸네일에서는 상단 부정 문장·하지만·하단 상세를 접어 근거 변화에 집중하고, 큰 보기에서는 전체 내용을 보여준다. 각 디자인은 실제 DOM 텍스트와 CSS로 제작한다.

실제 본문의 근거 문장은 선택 전 그대로 둔다. 기존 공개 URL의 /previews/proof-concepts.html로 시안을 게시한다.

## 검증
실제 페이지의 mark 문구, 확대 수치, 기존 이미지 없는 도입, 스크롤 코드 보존을 확인한다. 네 시안의 PC 900px·모바일390/320px 가로 넘침 및 글자 일관성, 갤러리의 네 썸네일·각 링크·PC/모바일 전환을 확인한다. 시안 문장에 원문의 9년·3,165명·가르쳐본 결과·내린 결론이 모두 포함되어야 한다.


## 사용자 선택 — A 문장 강조
사용자가 A를 선택했고 문장을 ‘9년간 3,165명을 가르치고 내린 결론입니다.’로 줄이도록 요청했다. 실제 본문의 reality-proof에 A 스타일을 적용한다. 9년간·3,165명만 동일 크기 700 굵기와 파란 밑줄로 강조한다. 본문20px, 모바일17px. 최대폭680px, 상단간격30px(모바일26px). 시안 A도 동일한 최종 문장으로 갱신한다. 다른 세 시안은 비교 기록으로 보관한다.

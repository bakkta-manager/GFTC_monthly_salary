# 도입 핵심 단어 강조 시안 설계

2026-10-15

## 공통
- previews/intro-keyword-colors.html에 비교 갤러리 및 개별 보기 구현.
- 각 안마다 현재 집 장면과 스포츠카 장면을 모두 표시한다. 이미지와 오버레이는 배포 v23 기준이다.
- index.html의 도입 CSS·HTML을 복사하여 실제 글자 크기, 굵기, 자간, 줄바꿈을 동일하게 유지한다.
- ‘코인’, ‘건물’, ‘트레이딩’, ‘수십억’에만 span.keyword를 적용하고 나머지 글자는 흰색이다.
- A 아이스 블루: #7CB0FF 단색. 기존 파랑 계열과 가장 자연스러워 추천.
- B 샴페인 골드: #E6C78A 단색. 집·스포츠카의 고급스러운 분위기를 강조.
- C 쿨 민트: #76DCC7 단색. 차갑고 선명한 인상.
- D 블루 마커: 글자는 흰색, 단어 하단에 #3B82F6의 70% 불투명도 배경. 기존 밑줄 강조와 연결.
- 강조로 인한 글자 폭·크기·배치 변화가 없도록 padding과 굵기를 추가하지 않는다.

## 비교 UI
4개 안을 2열 카드로 표시하며 카드마다 집·차 미리보기를 나란한 순서로 보여준다. 작은 화면에서는 한 열이다. 카드는 1440×1800 두 화면 iframe을 축소하되 실제 콘텐츠가 잘리지 않는다.
개별 보기에는 A–D 전환, PC·모바일 전환, 전체 비교 링크를 제공한다. iframe은 1440px PC 또는 390px 모바일의 실제 viewport로 렌더한 후 가용 폭에 맞게 축소한다.
키보드 포커스, iframe 제목, 현재 탭 표시, URL 파라미터 allowlist를 적용한다.

## 검증
네 안의 네 키워드, 공통 서체 크기, 이미지 로딩과 현재 오버레이가 일치하는지 확인한다. PC 1440 및 모바일 390에서 화면을 보고 전체 비교와 개별 전환을 확인한다. 본 랜딩 HTML은 수정하지 않는다.

## 사용자 선택 — A 적용
사용자가 A를 선택했다. 본 랜딩의 코인/건물/트레이딩/수십억에만 #7CB0FF를 적용한다. 글자 크기와 굵기, 배경·오버레이는 그대로 유지한다.

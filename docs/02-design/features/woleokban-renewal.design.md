# 월억반 리뉴얼 설계

Date: 2026-10-20
Plan: ../../01-plan/features/woleokban-renewal.plan.md

## 페이지 구조
1. 네비게이션: 월억반 / 글로벌트레이더협회, 상담 신청.
2. 첫 화면: 기존 집 영상, GFTC 월억반·9개월, 수익을 내는 방법에서 수익을 확장하는 방법으로, 상담 CTA.
3. 2026-10-20 후속 요청: 자동차·신문의 나란한 보조 장면 두 개를 삭제한다. 첫 화면 다음에는 종이 질감 메시지를 바로 배치하고, 삭제된 영역의 여백도 남기지 않는다.
4. 종이 질감 메시지: 더 큰 수익을 목표로 할수록 더 정교한 매매 기준이 필요합니다.
5. 대상의 고민 3가지와 월백/월천/월억 과정 비교. 단계별 수강을 필수 조건으로 표현하지 않음.
6. 중앙 배치·왼쪽 정렬의 교육 탄생 배경. 내부 양성 과정의 이론/실전/교정 방식 설명.
7. 커리큘럼: 9개월 전체 기간, 이론과 매매 기준 → 실전과 행동 교정 → 수익 확장과 자본 운용. 단계별 기간은 미표시. 공개 개요 + 기존 블러 자료.
8. 라이트 훈련 섹션: 직접 실행/매매 기록/행동 교정. 기존 일지·ZOOM 참여 기준은 유지.
9. 혜택: 심화 이론·W.E.T·라이브 매매 관찰·시황과 뉴스·학습 관리·커뮤니티.
10. 월 55만 원, 9개월 과정 요약과 상담 버튼 유지. 2026-10-20 후속 요청에 따라 아래 FAQ 4개만 삭제하고 해당 영역에 빈 여백을 남기지 않는다.
11. 기존 상담 폼과 안내문. 문구만 월억반에 맞추고 제출 API 계약 보존.

## 레이아웃
- Pretendard, 기존 near-black·blue·warm-paper 팔레트와 미세 질감 유지.
- 전체 배경은 full bleed, 본문은 최대 56rem 중앙 배치, 텍스트 왼쪽 정렬.
- 첫 화면 headline clamp 36px–80px. 보조 장면의 전용 레이아웃과 문구는 제거한다.
- 영상 pause 버튼 및 viewport/reduced-motion 처리 유지.
- 세 장면 강제 wheel/touch 스크롤 코드는 제거, 일반 문서 스크롤 사용.
- 새 목록/비교는 단순 구분선과 큰 숫자로 구성; 반복되는 장식 카드 최소화.
- FAQ와 FAQ 전용 스타일은 삭제한다.

## 데이터/API
- FORM_ENDPOINT, FORM_PUBLIC_KEY와 서버 요청 payload/허용값 변경 없음.
- 기존 필수 항목 유지. 긴 지원 동기 요구 표현만 상담에서 다루고 싶은 고민을 적는 표현으로 완화.
- 기존 수입 목표 선택값은 서버 호환성을 위해 유지하고 현재 목표를 묻는 진단 질문으로 표기.
- 월급반 제품명은 frontend metadata, labels, privacy purpose, completion copy에서 월억반으로 변경.
- 운영 중인 backend, DB record, source repo identity 및 공개 범위 변경 없음.

## 제외 조건
- 임의의 3개월별 단계 배분, 자동 결제·최소 기간·환불 정책 없음.
- 1:1 진단 및 라이브 횟수·일정·대상 조건 미표시. 1:1 보장 문구도 이번 버전에서 제외.
- 월 1억 수익을 보장하거나 기존 95% 동일 등의 확인되지 않은 수치를 사용하지 않음.

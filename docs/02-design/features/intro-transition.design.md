# 도입부 전환 문구 설계

2026-10-15 · intro-transition

이전 말풍선 해석을 폐기하고 사용자가 명시한 세로 연결 구조로 수정한다.

- 첫 번째 section.letter의 letter-turn 클래스를 배치 기준으로 유지한다.
- .letter + .letter-turn의 가로 테두리만 제거한다. 다음 본문 구분선은 유지한다.
- 기존 p.turn은 배경 없는 ‘하지만’ 텍스트로 표시한다. 18px/1.45, 굵기 500, 기존 --accent2 색상.
- p.turn을 세로 flex로 구성하고 ::before/::after로 위아래 각각 폭 2px, 높이 44px의 세로선을 배치한다. 텍스트와 간격 16px. 옅은 파란색을 사용한다.
- 연결 요소 전체를 섹션 경계 중앙에 left:50%, top:0, transform:translate(-50%,-50%)로 배치한다. 양쪽 본문 패딩과 제목은 유지한다.
- 모바일은 세로선 높이 32px, 간격 14px로 줄여 기존 여백 안에 배치한다.
- PC 및 390/320px 모바일에서 위아래 세로선·중앙 텍스트·본문 비겹침·가로 넘침을 확인한다.

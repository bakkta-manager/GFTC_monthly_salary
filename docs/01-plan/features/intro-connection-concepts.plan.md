# 도입부 연결 시안 4개

2026-10-15 · intro-connection-concepts

사용자는 왼쪽 본문과 중앙 세로 연결 요소의 이질감을 줄이는 4개 시안을 요청했고, 자연스러운 읽기 흐름을 우선해 판단하도록 했다.

도입부 두 섹션의 글과 순서, 어두운 블로그 톤, 파란 강조를 유지한다. 선과 ‘하지만’의 관계, 문단 정렬과 여백만 다르게 제안한다. 실제 index.html은 유지하고 별도 비교 페이지에서 선택하도록 한다.

완료 기준: 구별되는 시안 4개, 자연스러움 기준 추천안 표시, 현재 배치와 비교, PC/모바일 보기, 원문 보존 및 넘침 검증.

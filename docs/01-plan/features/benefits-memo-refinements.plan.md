# F 메모형 발전 시안 4개

2026-10-15

## 목적
사용자가 고른 제공 혜택 F 메모형의 방향을 발전시킨 4개 시안을 제공한다. 이전 블로그형 제약과 글 중심 구성을 유지한다.

## 범위
두 열 메모 배치, 작은 선 아이콘, 어두운 바탕, 6개 혜택 원문 및 순서를 공통 기준으로 한다. 신규 시안은 F1~F4로 표시하고 기존 F를 비교 기준으로 제공한다. 원본 및 이전 시안은 수정하지 않는다.

## 완료 기준
F1~F4의 차이가 여백·제목 배치·첫 문장 강조·카드 경계에서 드러난다. PC 두 열 및 모바일 한 열, 모션 감소 지원. 실제 브라우저에서 원문 일치·레이아웃·비교 기능을 확인한다.

# 블로그형 도입부 시안 수정

2026-10-15 · 사용자 교정: 블로그 컨셉을 유지해야 하며 이전 시안은 변경 폭이 과도했다.

## 목표
첫 두 섹션의 원문, 문장 순서, 어두운 배경, 한 열 본문, 기존 폭을 유지한 네 시안을 제공한다. 이미지·핵심 문장 강조·조용한 등장 모션을 글 안에 포함한다.

## 범위
비교용 previews/intro-concepts.html을 교체한다. 원본 index.html은 선택 전 유지한다. 본문 가로 분할, 전체 폭 배경 이미지, 대형 성과 숫자, 3D 오브젝트, 반복 모션은 사용하지 않는다.

## 성공 기준
모든 시안에서 첫 두 섹션 원문의 문장 및 순서가 동일하다. 본문 max-width 736px, 기존 IBM Plex Sans KR와 색상 유지. 제목은 36~40px, 본문 17px. 본문 사진은 1장씩 배치하고 320px/390px/1440px에서 줄바꿈 확인. 기존 비교·모바일·다시 보기 기능 유지.

## 추가 요청
사용자가 세 가지 문제 구간의 시안 4개도 함께 요청했다. 총 도입부 4안 + 문제 구간 4안을 제공한다. 문제 구간의 '솔직하게 말씀드리면'은 원본 및 모든 시안에서 삭제한다. 원본 수정은 이 문구 삭제에 한정한다.

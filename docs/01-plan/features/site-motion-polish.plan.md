# 사이트 모션 보완 계획

2026-10-15 · site-motion-polish

사용자 요청: 전체 사이트 곳곳에 CSS 애니메이션을 추가해 생동감을 높인다.

- 기존 문구, 다크·라이트 배경, 타이포그래피, 스크롤 전환, 폼 동작을 보존한다.
- 본문·커리큘럼·신청 제목을 스크롤 시 순차 등장시켜 구간 사이 흐름을 연결한다.
- 사진의 짧고 느린 줌, 강조선 그리기, 혜택 카드·버튼·폼 선택의 미세한 반응을 추가한다.
- 반복 모션은 짧고 유한하게 하며 모바일에서도 내용 읽기와 터치 스크롤을 방해하지 않는다.
- 외부 라이브러리 없이 CSS keyframes/transition 및 기존과 같은 IntersectionObserver로 구현한다.
- 동작 줄이기, JavaScript/IntersectionObserver 미지원, 키보드 초점에서 내용과 폼 접근성을 보장한다.
- 검증: 1440/390/320px, 일반·동작 줄이기·JS 비활성, 빠른 스크롤, 카드 호버, 폼 단계 전환, 본문 보존과 가로 넘침을 확인한다.

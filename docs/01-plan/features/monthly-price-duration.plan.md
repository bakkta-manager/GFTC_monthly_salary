# 월 수강료 및 기간 안내 수정

Date: 2026-10-24

사용자 확정 사항: 수강료는 월 29만 원이며 9개월 과정이 아니다. 첨부한 커리큘럼 섹션 전체를 삭제한다.

현재 공개 버전 41을 기준으로 변경한다. 모든 고정 9개월 안내(본문, 폼, 메타 설명)를 제거하고 새로운 기간·약정·자동 결제 정책을 추측하지 않는다. 가격은 상담 신청 앞에서 명확히 안내한다. 나머지 혜택은 변경 자료가 주어질 때까지 유지한다.

완료 기준: 커리큘럼 섹션과 전용 스타일 제거, 월 29만 원 표시, 9개월 문구 없음, 기존 폼 필드 계약 유지, 반응형 확인 및 기존 공개 사이트 배포.

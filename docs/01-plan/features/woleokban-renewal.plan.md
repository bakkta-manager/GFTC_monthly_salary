# 월억반 리뉴얼 계획

Date: 2026-10-20

## 목적과 근거
- 10월 19일 녹음 2건을 검토한 수정 제안과 사용자의 후속 결정을 반영한다.
- 월백반(무료), 월천반(월 29만 원), 월억반(월 55만 원)의 교육 방향을 구분한다.
- 월억반은 트레이딩 내 수익 확장과 자본 운용을 훈련하는 심화 과정으로 설명한다.
- 사용자가 9개월 유지, 결제·최소 이용 기간 및 1:1 진단·라이브 세부 조건의 생략을 확정했다.

## 범위
- 브랜드·메타·폼·동의 목적 문구를 월억반으로 통일한다.
- 도입을 줄이고 첫 화면에 교육 목표와 상담 CTA를 표시한다.
- 기존 영상 3개, 검정/블루 강조, 종이 질감과 중앙 배치 본문을 재사용한다.
- 대상, 과정 비교, 차별점, 커리큘럼 큰 흐름, 훈련 방식, FAQ를 정리한다.
- 9개월 전체 교육 기간만 명시하고 단계별 개월 수를 임의 배정하지 않는다.
- 월 55만 원만 표시하며 결제 방식·최소 이용 기간·환불·1:1 진단 조건을 새로 만들지 않는다.
- 폼 데이터 계약, 서버 검증, 저장 목적지와 기존 기록은 유지한다.

## 제외
- 결제 구현, Supabase 프로젝트/테이블 변경, 기존 상담 데이터 수정.
- 확인되지 않은 수익 실적, 보장 문구, 진단 횟수와 라이브 일정 추가.
- 새 영상 제작, 주소/공개 범위 변경.

## 완료 기준
- 월급반 명칭과 월급 수입 약속이 페이지 본문·메타에서 제거된다.
- 월억반 목표와 9개월 과정, 월 55만 원이 일관되게 표시된다.
- 공개 커리큘럼 개요와 상세 자료 블러 박스가 함께 제공된다.
- 모바일/데스크톱 가로 넘침과 콘솔 오류 없이 상담 폼 단계가 작동한다.
- 이전 폼 payload 필드/허용값과 서버 호출은 유지된다.
- 같은 Sites 프로젝트에 배포하고 public 공개 범위를 보존한다.

## 일정과 위험
- 이번 작업에서 설계 → 구현 → 화면/폼 검증 → 배포까지 완료한다.
- 장면 수 변경으로 인한 자동 스크롤 오류는 강제 장면 전환 코드를 제거해 방지한다.
- 긴 문장은 반응형 크기·최대 폭으로 제어한다.
- 새 운영 조건은 사용자 확인 전 표시하지 않는다.

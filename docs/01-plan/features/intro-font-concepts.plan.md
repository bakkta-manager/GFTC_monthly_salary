# 도입 간격·본문 흐름 정리와 폰트 시안 6개

2026-10-15 · intro-font-concepts

사용자 요청: 도입 메시지의 두 줄 간격과 하이라이트를 정리하고 폰트 시안 6개를 제시한다. 후속 요청으로 대표 서명 제거, 마무리 두 문장의 같은 위계 통합, 첫 문제 점 위 세로선 삭제, 문제·혜택 설명의 문장별 줄바꿈을 함께 반영한다.

메인에는 간격/본문 수정만 적용하며 폰트는 선택 전까지 유지한다. 시안은 동일 문구·크기·색으로 6종 실제 글꼴을 비교하고 PC/모바일 큰 보기를 제공한다. 완료 기준은 6종 글꼴 실재 로딩, 비교 화면·메인 수정 검증, 공개 링크 제공이다.

# Content width balance — plan

2026-10-15

## 목적

왼쪽 정렬 문장이 넓은 화면의 왼쪽에 치우쳐 보이는 문제를 해결한다. 사용자는 사이트 전체 섹션의 가로 너비와 중앙 배치를 요청했다.

## 범위와 판단

현재 일반 .wrap/.letter 본문은 46rem 최대 너비와 auto 좌우 마진으로 중앙에 있다. 최근 확대한 evidence/probs는 본문 너비가 1280px여서 짧은 문장이 왼쪽으로 치우쳐 보인다. 확대된 두 섹션의 본문 너비를 896px로 제한하고 동일한 중앙 기준을 적용한다. 일반 본문/폼/네비게이션은 더 좁은 기존 중앙 영역을 유지한다. 영상/라이트 섹션의 배경은 화면 전체를 채운다.

## 완료 기준

- 증거와 과정의 본문 좌우 여백이 동일하고 왼쪽 텍스트 정렬이 유지된다.
- 모든 주요 섹션의 본문 컨테이너가 중앙에 놓인다.
- 1920,1440,1024,768,390,320px에서 가로 넘침이 없다.
- 문구, 폼 동작, 영상 재생 및 전체 화면 최소 높이를 유지한다.
- 화면 검토 후 기존 공개 사이트에 반영한다.

Supabase 연결은 별도 consultation-form 작업으로 대기 중이다.

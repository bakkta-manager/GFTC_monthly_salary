# D 도입 정렬형 적용 및 공유

2026-10-15 · intro-d-public-share

사용자가 선택한 D 시안을 실제 랜딩 페이지에 적용하고 다른 사람에게 전달해 열 수 있는 공개 URL을 제공한다. 원문과 앞서 선택한 문제·혜택 디자인을 유지한다.

Sites의 별도 정적 사이트 디렉터리에 실제 페이지를 패키징해 게시한다. 비교 시안, 작업 문서, 로컬 데이터는 배포하지 않는다. 연결되지 않은 상담 접수를 완료로 오인하지 않도록 공유 화면에 접수 미지원 안내를 표시한다.

완료 기준: D 시안과 PC/모바일 일치, 원문 유지, 공개 접근 설정, 배포 성공 URL 확인.

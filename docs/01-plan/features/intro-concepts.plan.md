# 도입부 디자인 시안 4종

Date: 2026-10-15

## 목적과 범위
사용자가 지정한 첫 두 섹션을 이미지, 타이포그래피, 애니메이션을 포함한 실제 브라우저 시안 네 가지로 제안한다. 기존 index.html은 선택 후 적용할 수 있도록 유지한다.

## 목표
- A 편지형, B 대비형, C 숫자 신뢰형, D 훈련 시스템형을 서로 다른 레이아웃으로 구현한다.
- 각 시안에 맞춘 실제 이미지 파일과 작동하는 애니메이션을 넣는다.
- 기존 문구의 핵심 내용, 9년, 3,165명, 세 가지 훈련 요소를 유지한다.
- 1440px 데스크톱 및 390px 모바일에서 실제 렌더링을 확인한다.
- 비교 화면, 개별 시안 링크, 모바일 미리보기, 모션 다시 보기 기능을 제공한다.

## 완료 기준
네 시안에 이미지가 정상 로드되고, 모바일 가로 넘침이 없으며, 모션 감소 설정을 존중한다. 수익 차트나 새로운 성과 통계를 만들지 않는다. 생성 이미지는 시안용 연출 이미지로 안내한다.

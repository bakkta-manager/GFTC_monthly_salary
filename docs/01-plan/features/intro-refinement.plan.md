## 사용자 요청
- 첫 인용문은 집 실사 사진, 둘째 인용문은 스포츠카 실사 사진을 배경으로 각각 한 화면에 표시한다. 생성 이미지를 사용하지 않고 온라인 사진을 찾는다.
- 도입의 큰 글자에 동일한 크기·굵기·색 기준을 적용한다.
- 누구나 꿈꾸지만 / 아무나 이룰 수 없는 목표입니다를 PC 두 줄로 되돌리고 ‘아무나 이룰 수 없는 목표’ 전체를 강조한다.
- 첫 두 화면에서만 페이지 단위 스크롤을 사용한다. 세 번째 화면 이후는 일반 스크롤이다.
- 현실적 수입, 9년·3,165명 근거, 관리 시스템·학습·훈련·행동 교정·결과를 하나의 섹션으로 묶은 시안 4개를 제공한다. 글이 중심인 블로그 컨셉과 기존 파란 강조를 유지한다.
- ‘소수 정예 운영 / 위 커리큘럼을 참고하시고, 충분히 고민 후 결정해주세요’ 독립 CTA 섹션을 삭제한다.

공통 변경을 기존 공유 URL에 반영하고 네 가지 시안을 비교할 공개 링크를 제공한다. 화면 크기에 따른 오버플로, 타이포그래피 일관성, 사진 로딩, 초기 페이지 스크롤과 이후 자유 스크롤을 확인한다. 나머지 문제·혜택 본문은 보존한다. 시안 최종 선택은 사용자에게 남긴다.

# 도입 핵심 단어 강조 시안

2026-10-15 · 사용자 요청

집 장면의 ‘코인’, ‘건물’과 자동차 장면의 ‘트레이딩’, ‘수십억’에 강조 색상을 주는 시안 4개를 제안한다. 현재 Pretendard와 글자 크기, 생성 배경, 검은 오버레이를 기준으로 비교한다.

기존 랜딩은 유지하고 독립 비교 페이지를 같은 사이트에 게시한다. 전체 비교와 개별 크게 보기, PC·모바일 확인을 제공한다. 색 선택은 사용자가 한다.

완료 기준: 네 안 모두 정확한 네 단어만 강조되고, 배경·글자 크기가 서로 일치하며, PC·모바일에서 이미지·폰트가 로드되고 가로 넘침이 없어야 한다.

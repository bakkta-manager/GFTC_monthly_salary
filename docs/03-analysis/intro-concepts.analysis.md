# 도입부 시안 검증

Date: 2026-10-15 · Feature: intro-concepts

## 설계 대비 확인
요구사항 12개 중 12개 충족. 수치는 아래 기능 체크리스트 기준이며 미적 완성도의 객관적 점수가 아니다.

- [x] A 시네마틱 레터 구성과 야간 데스크 이미지
- [x] B 좌우 대비 구성과 도시 이미지
- [x] C 큰 숫자 및 밝은 지면과 학습 이미지
- [x] D 3단계 훈련과 유리 계단 이미지
- [x] 기존 핵심 문구와 9년·3,165명 유지
- [x] 문장 순차 등장과 밑줄 모션
- [x] 숫자 카운트
- [x] 훈련 단계 순차 활성화·일시정지
- [x] 네 시안 비교 및 개별 링크
- [x] PC/모바일 폭 전환·모션 다시 보기
- [x] 1440px, 390px, 320px에서 페이지 가로 넘침 없음
- [x] reduced-motion에서 모든 모션 비활성화

## 실행 검증
실제 Chrome의 Playwright 렌더링. 4개 시안 × 3개 화면 폭에서 모든 이미지 로드 성공, JavaScript 오류 없음. 1440px/390px 스크린샷을 육안 확인했다.

D 인터랙션 검증: PC 프레임 높이 1412px → 모바일 1781px → PC 1412px로 복원. 단계 활성화 변경 확인, 일시정지 후 활성 단계 유지 확인, 다시 보기 후 숫자 9·3,165 확인. 모션 감소 설정에서 activeAnimations=0, 모든 reveal 콘텐츠 표시, 일시정지 버튼 숨김 확인.

D의 320px 이미지 영역은 의도적으로 가장자리로 확장되고 scene 영역에서 잘린다. 텍스트 잘림이나 페이지 가로 스크롤은 없다.

## 조정 사항
iframe 높이는 문서 스크롤 높이가 아닌 실제 시안 요소 높이를 사용하도록 수정하여 모바일에서 PC로 전환할 때 남는 공백을 방지했다. 제목 크기는 화면 폭과 한글 줄바꿈에 맞춰 설계의 기준 크기에서 조정했다.

## A Pretendard 확정 적용 검증

메인 공통 글꼴에 시안 A와 같은 Pretendard 원본을 적용했다. 1440/390/320px에서 제목·본문·혜택·하단 안내·폼 입력 요소가 모두 Pretendard를 사용하며 로딩에 성공했다. 가로 넘침과 JS 오류 없음. 도입 첫 세 장면의 크기는 각각 82.08/39/32px로 장면 간 일치한다. 선택한 행간·간격·하이라이트 유지. body 이하 전체 HTML/JS는 수정 전과 동일함을 대조했다. 증거: previews/screenshots/pretendard-applied/checks.json 및 화면 이미지.

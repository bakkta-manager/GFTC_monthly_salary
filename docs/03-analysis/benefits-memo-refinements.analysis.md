# F 메모형 발전 시안 검증

2026-10-15 · benefits-memo-refinements · check

설계 문서의 F1~F4를 별도 비교 페이지에 구현했다. 6개 혜택의 원문 및 순서, 작은 선 아이콘, 어두운 배경과 글 중심 구성을 유지했다.

## 검증 결과
- Playwright Chromium으로 4개 시안 × 1440/390/320px 총 12개 조합 확인: 항목 6개, 아이콘 6개, 공백 정규화 후 원문 일치.
- PC 두 열, 모바일 한 열 확인. 페이지 및 본문 가로 넘침 없음. JavaScript 오류 없음.
- 갤러리 전체와 모바일 F1/F4 실제 렌더 확인. 제목·본문·구분선의 겹침 없음.
- 기존 F 비교 탭의 계산된 스타일과 요소 크기가 이전 F 시안과 1440/390px에서 일치.
- PC → 모바일 → PC 전환 시 iframe 높이가 1220 → 1685 → 1220px로 정상 복원. 320px 상단 도구 영역 넘침 없음.
- 기존 F 선택 시 항목 6개 표시. F2 전환 및 다시 보기 후 제목 표시 확인.
- 모션 감소 설정에서 활성 애니메이션 0개, 모든 항목 표시.
- index.html 및 이전 benefits-concepts.html SHA256이 작업 전과 일치.

증거: previews/screenshots/memo/verification.json, overview.png 및 f1-390.png~f4-390.png.

설계 체크리스트에서 미해결 기능 차이를 발견하지 않았다. 미적 선호와 최종안 선택은 사용자 검토 사항이다.

## 후속 오류 수정 — 연속 휠 입력 차단
실제 공개 버전에서 75회 연속 휠 입력(55px, 40ms 간격)을 보냈을 때 두 번째 화면 scrollY 835에서 멈추는 문제 재현. 기존 테스트는 짧은 입력의 장면 건너뛰기 방지에 집중해 장시간 연속 입력의 차단을 놓쳤다.

잠금의 만료 시점을 매 이벤트마다 갱신하지 않고 페이지 전환 시작 기준 760ms로 고정했다. 동일 연속 입력은 수정 후 scrollY 4475(일반 모션), 4035(모션 감소)에 도달해 본문으로 이어졌다. 짧은 입력은 835 → 1670으로 한 장면씩 이동, 이후 80px 입력은 1750으로 일반 스크롤. 역방향 연속 입력은 0까지 복귀. 6회 짧은 휠 묶음은 835에 정지. JS 오류 없음.

## C 기록형 원본 적용 검증
사용자 선택에 따라 문제 구간 C를 index.html에 반영했다. 세로 여백선·파란 점·핵심 문장 형광펜·한 번의 등장 모션을 적용했다.

실제 페이지와 C 시안의 h2/sub/문단/항목/핵심 문장에 대해 폰트 크기, 행간, 굵기, 자간, padding, margin, 요소 폭을 비교했다. 1440px에서 모두 일치. 모바일에서 발견한 제목 자간 차이는 -0.04em으로 보정하고 390px에서 -1.12px 적용을 재확인했다. 390px/320px 텍스트 및 가로 넘침 검사 통과. 문장 일치, JavaScript 오류 없음, 모든 등장 대상 표시 확인.

승인 구간 CSS·강조 span·구간 id·구간 모션 추가를 제외하면 변경 전 파일과 정확히 일치한다. 도입부, 다른 본문, 기존 신청 폼 스크립트는 그대로 유지되었다.

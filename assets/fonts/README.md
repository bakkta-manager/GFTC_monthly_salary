- SUIT v2.0.5: https://github.com/sun-typeface/SUIT · SIL OFL, suit-license.txt
- Noto Sans KR: https://github.com/google/fonts/tree/main/ofl/notosanskr · SIL OFL, noto-sans-license.txt
- Wanted Sans v1.0.3: https://github.com/wanteddev/wanted-sans · SIL OFL
- 나눔스퀘어 네오: https://hangeul.naver.com/fonts · 네이버 공식 웹폰트 https://hangeul.pstatic.net/hangeul_static/css/nanum-square-neo.css

Noto 2종은 공식 variable TTF를 시안에 쓰인 문자로만 subset하여 TTF로 제공한다. 다른 글꼴은 공식 배포 웹폰트 원본이다. 개별 원본 다운로드 주소는 sources.json을 참고한다.
